# copilot-sandbox

Sandbox repository for AI Engineering System copilot draft PR validation.
Not production. Safe for automated draft PR tests.

## Environment Variables

The following environment variables can be used to configure the application:

- `MAX_RETRIES`: Maximum number of retries for connection attempts (default: `3`)
- `TIMEOUT`: Timeout for connection attempts in seconds (default: `30`)
- `CONNECTION_POOL_SIZE`: Size of the connection pool (default: `10`)
